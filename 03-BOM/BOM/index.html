    Bill of Materials

    Overview

    The following Bill of Materials lists the components used in the Fill-A-Bot Liquid Amount Sensing subsystem. The subsystem uses a 1 kg load cell and NAU7802KGI 24-bit ADC to measure liquid weight, a PIC18F57Q43 Curiosity Nano for processing and control, and a four-wire direct digital interface for communication with the main controller.

    The team interface uses two command inputs, C1 and C0, to select one of four weight presets and two status outputs, S1 and S0, to report the current state of the Liquid Amount Sensing subsystem.

    Team Interface

    The Liquid Amount Sensing subsystem communicates with the main controller through J1 using four direct digital signals.

    J1 Pin Signal PIC Pin Direction
    1 C1 RA3 Input
    2 C0 RA4 Input
    3 S1 RE2 Output
    4 S0 RC7 Output
    5 NC — Unused
    6 NC — Unused
    7 NC — Unused
    8 GND GND Common ground

    C1 and C0 form the two-bit weight command input. R7 and R8 provide 100 kΩ pull-down resistance on these inputs so that both command lines default LOW when no command is being driven.

    The weight command uses the following encoding:

    C1 C0 Command
    00 Preset 1
    01 Preset 2
    10 Preset 3
    11 Preset 4

    S1 and S0 form the two-bit weight status output from the Liquid Amount Sensing subsystem to the main controller.

    The weight status uses the following encoding:

    S1 S0 Status
    00 Not ready
    01 Below target
    10 Target reached
    11 Error

    The S1 and S0 outputs are initialized LOW by the subsystem software.

    Notes

    The NAU7802KGI is mounted directly on the subsystem PCB rather than using a separate ADC daughter board.

    The team interface does not carry subsystem power. J1 Pins 1 through 4 are used for the C1, C0, S1, and S0 direct digital signals, Pins 5 through 7 are unused, and Pin 8 provides the common ground connection between the Liquid Amount Sensing subsystem and the main controller.
